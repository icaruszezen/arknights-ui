# 官网

> 一个固定骨架，六屏内容。黑底、单一青蓝、双语标签、背景巨字——整套设计语言最干净的一次呈现。

实测对象：[ak.hypergryph.com](https://ak.hypergryph.com/)，2026-10-06，视口 1280 × 720。

## 结构

官网是一个纵向分屏的单页，六屏通过锚点切换：

| # | 锚点 | 英文 | 中文 | 内容 |
| --- | --- | --- | --- | --- |
| 00 | `#index` | INDEX | 首页 | 主视觉、下载入口 |
| 01 | `#information` | INFORMATION | 情报 | 新闻列表 + 活动轮播 |
| 02 | `#operator` | OPERATOR | 干员 | 干员立绘、简介、缩略图切换 |
| 03 | `#world` | WORLD | 设定 | 世界观名词条目 |
| 04 | `#media` | MEDIA | 泰拉万象 | 等距场景导航：画廊、音乐、干员、视频 |
| 05 | `#more` | MORE | 更多内容 | 集成战略、生息演算、衍生动画、泰拉记事社 |

### 固定骨架

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 顶栏 | 顶部通栏，高 `6.75rem`，叠在内容上 | 左：Logo；中右：六个双语导航项；最右 `14.75rem`：分享、音频、账号三个图标。自上而下垫一道黑色渐变，下缘没有线 |
| 右栏 | 右侧 `14.75rem`，左缘一条竖线 | 栏目计数 `01 // 01 / 05` + 栏目英文名；首页另有下载与社交入口 |
| 横线 | 横贯整屏，只有一条 | 情报、干员两屏在距顶 `9.5rem` 处；首页、设定、泰拉万象、更多内容在距底 `11.25rem` 处 |
| 幽灵标题 | 左 `8.375rem`，挂在距底 `11.25rem` 的线下 | 本屏英文名的巨字（BREAKING NEWS、WORLD、ABOUT TERRA、MORE CONTENT），上缘被裁掉一截 |
| 滚动提示 | 距底 `3.75rem`，相对整屏居中 | 一行 `SCROLL` 加一个向下的箭头 |
| 背景 | 全屏 | 近黑底 + 网格线 + 一张用叠加模式盖上去的半调图 |

骨架在切屏时不动，只有导航高亮、计数数字、幽灵标题和那条横线随屏更新。

### 竖屏的骨架

竖屏（视口高 ≥ 宽）是另一套编排，不是把横屏缩小。骨架还是那几样东西，位置和大小都换了。

竖屏样式表里的 rem 以 **750 宽**为基准（见下面“响应式”一节的根字号）：375 宽的手机上根字号是 8px，同样的 rem 值实际只有横屏的一半大。下表第二列是样式表里的值，第三列是折半以后的值，也就是根字号 16px、375 宽时该用的值。

| 位置 | 样式表里的值（750 基准） | 折半（375 基准） |
| --- | --- | --- |
| 顶栏 | 高 `9.375rem`；Logo 宽 `10.25rem`、左距 `1.75rem`；渐变只剩两段，`linear-gradient(0deg, transparent, rgba(0,0,0,.8))`；主导航不显示 | 高 `4.6875rem`；左距 `0.875rem` |
| 顶栏右端 | 三个图标占 `15rem`（右内边距 `0.75rem`）；再往右一格 `5.75rem` 是菜单按钮：三条 2px 的横杠，`2.625rem × 2.375rem` | 菜单按钮那一格 `2.875rem` |
| 右栏 | 仍在右边，宽 `5.75rem`，左缘一条竖线。上面是菜单按钮，底下是计数 | `2.875rem` |
| 竖线、横线 | 1px，`rgba(255,255,255,.5)`，比横屏亮一档 | 同左 |
| 横线 | 首页在距底 `12rem` 处；其余五屏都在距顶 `9.375rem` 处，也就是顶栏的下缘 | `6rem`、`4.6875rem` |
| 计数 | 整块宽 `4rem`，在右栏里居中，下缘距底 `12.5rem`。大数字 `3.6rem`、居中，同样裁掉下缘；“// 01 / 05” `1rem`、竖排（`writing-mode: vertical-rl`），贴整块的右下角；栏目名 `0.625rem`、竖排，右距 `1.5rem`、贴底；微缩字不显示。两行竖排的字压在数字上 | 宽 `2rem`、距底 `6.25rem`；`1.8rem`、`0.5rem`、`0.3125rem`；右距 `0.75rem` |
| 幽灵标题 | 字号还是 `7rem`；左 `2.875rem`（设定屏 `4.25rem`），挂在这一屏内容块的下面；情报屏不显示 | `3.5rem`；左 `1.4375rem` |

| 内容 | 从顶栏的下缘起，右边到竖线。情报屏的轮播贴着顶栏和左右两边（`41.125rem × 24.125rem`），下面的文字左右各留 `1.75rem` | 留 `0.875rem` |
| 更多内容屏 | 四条带改成上下叠着的横带，一共占屏高的 74.5%；文字块左 `7.5rem`、距底 `3.625rem`，标题仍是 `3.375rem`；色带换成横向的 `linear-gradient(90deg, transparent, 色 20%, transparent 70%)`、90% | 左 `3.75rem`、距底 `1.8125rem`；标题 `1.6875rem` |
| 全屏菜单 | 底色 `rgba(0,0,0,.9)`，让出顶栏和右栏；每项一行，高 `7.5rem`，英文 `2.25rem`、中文 `1.75rem`；最下面一栏 `TOOLBOX`，是一排社交图标 | 行高 `3.75rem`；`1.125rem`、`0.875rem` |

各屏的内容在竖屏也各有一套编排，这里只记了骨架和上面几项：

- 设定屏不排成一列条目，直接显示一个条目的标题（`3.75rem`）、英文（`2rem`）和说明（`1rem`），左右各一个箭头，下面一条分成六段的进度条。
- 首页右栏里的下载、社区、支付入口，竖屏时挪进了首页的内容区，排成一列按钮。
- 干员屏的缩略图换成 `8.125rem × 9.625rem`：上面一张 `8.125rem` 见方的图，名字贴着底边写，框是灰的（`#555553`），当前项才变白。
- 新闻行高 `7.125rem`，标题 `1.25rem`、行高 1.6，日期 `1rem`，排在标题右边。

## 各屏拆解

### 首页 INDEX

- 全屏主视觉，人物偏右，被一块巨大的青蓝色块和巨型字母部分遮挡——色块与人物互相穿插，形成前后关系。
- 左下角是品牌字 `ARKNIGHTS`（Novecento Sans Wide UltraBold `5.5rem`、行高 0.75），右边跟两行小字：`RHODES ISLAND`（Novecento Sans Wide Medium `1.125rem`）与网址（`0.875rem`），小字下面一条 `6rem × 1px` 的白线。再往下是版权标记，那是一张 SVG 图形。整块入场时自下升起 `11.5rem`，1s。
- 右栏堆叠下载入口，每个是一条窄的色块按钮。

### 情报 INFORMATION

- 左侧窄列是新闻：顶部四个分类标签（当前项反白），下面三行新闻，每行“分类 / 日期 / 标题”。
- 右侧宽区是活动轮播，16:9（`83.125rem × 46.875rem`），右边出血到右栏竖线，左缘 20% 渐隐。下方一条 `0.5rem` 高的进度条：青蓝段表示当前，灰色为轨道。轮播上没有翻页按钮，也没有自己的计数。
- 左下一个青蓝主按钮“更多情报 / READ MORE”。
- 这一屏最能说明“不对称分栏”：列表很窄，图很宽。

### 干员 OPERATOR

- 左侧文字区：小标签 `PROFILE`（上面一行更小的 `RHODES ISLAND ://`）、英文名（小）、中文名（3.75rem 粗黑）、阵营三角徽记、声优信息、简介段落（**不透明**的黑底）。
- 右侧立绘出血，身后是同一张图的放大去色重影。
- 左下一排缩略图（现在是六张）：每张一圈白框，名字写在左下角；当前项从**右上角后面探出一块青蓝的三角**，其余的不压暗。
- 背景巨字是阵营或 `RHODES`。

### 设定 WORLD

- 六个名词条目纵向排列，每条是“中文粗黑（2.5rem）+ 英文（1.25rem 宽体）”，两者在**同一行**，下方一条 1px 的实白线。
- 各条**左缘对齐**。入场时逐条自左滑入，每条比前一条晚 200ms——滑到一半时看上去像一道阶梯。
- 文字默认是灰的（`#ababab`）。悬停某一条时，文字变**白**并向右位移 `2rem`，背后贴着右端浮现一行 25% 青蓝的巨型英文（`4.5rem`）。
- 这是内容最少的一屏，背景的斜线网格在这里最清楚。

### 泰拉万象 MEDIA

- 中央是一组等距视角的三维物件（工作台、显示器、无人机、收纳箱），每个物件旁有一个标注：GALLERY、MONSTER SIREN、OPERATOR、VIDEO。标注是一个带斜杠的小方框加一行灰字，没有引线。
- 点开某个物件后，它的标注换成一块图标加黑底青蓝字的标签；物件套上一圈白框，背后垫一块青蓝的方块。
- 左侧是标题组 `ABOUT TERRA` / `泰拉万象`，下方一条青蓝的粗条，再下是简介与网址，最后一条短细线。
- 左上角另有一个小导航：`ABOUT TERRA` 加四个带小方框的条目，当前项的方框填实。
- 场景的左下和右上各有一片点阵。
- 导航被做成了一个“场所”，而不是一排按钮。

### 更多内容 MORE

- 四条等宽竖带，各取一张插画的局部。条带铺满整屏，之间没有缝，靠每条右缘的一道暗边分开。

- 上下各压一道黑色渐变。每条另有一个从插画里取的主题色，横在下三分之一处。
- 悬停时图片放大，盖在上面的暗层退掉，主题色自下浮起；文字不变色，横线不变长。

### 加载屏

每次打开官网，先出现的是一屏加载：

- 底色 `#272727`，文字和线是 `#a4a4a4`。正中是游戏的标题标识。
- 进度条宽 `68.5rem`：一条 2px 的线，两端各一个 6px 的方块；青蓝的进度段 6px 高，压在线上。
- 进度条下面（上距 `0.75rem`）左边写 `LOADING - 20%`，Bender Bold；右边是品牌名（Bender Bold）和网址（Bender Regular）。
- 左下角是版权标记。
- 加载屏上也有骨架的两条线，位置比正式的骨架靠外（距顶、距右各 `6.625rem`），加载完成时以 1s 滑出画面。

### 响应式

| 项 | 做法 |
| --- | --- |
| 缩放 | 所有尺寸用 rem，根字号由页头的一段脚本按视口算，整体等比缩放。横屏以 1920 × 1080 为基准：`16px × min(宽 / 1920, 高 / 1080)`；竖屏（高 ≥ 宽）以 750 × 1334 为基准：`16px × min(宽 / 750, 高 / 1334)`。视口变化后 100ms 重算 |
| 断点 | 以 `(orientation: portrait)` 为主要切换条件（样式表中 353 条规则） |
| 竖屏 | 顶栏变高，导航收进全屏菜单，右栏收窄到只剩菜单按钮和竖排的计数；图片堆到列表上方；新闻行的日期移到右侧。取值见上面“竖屏的骨架” |

> **2026-10-08 更正。** 原先写的是“根字号 `100vw / 120`”，只对了一半：还有高度那一项（视口比 16:9 更宽时按高度算），竖屏另有一张 750 × 1334 的设计稿。
>
> 用 CSS 写出来是 `min(100vw / 120, 100dvh / 67.5)` 和 `min(100vw / 46.875, 100dvh / 83.375)`。

## 可借鉴的做法

1. **骨架与内容分离。** 导航、计数、幽灵标题构成一个不动的框，换屏只换内容。
2. **每屏一个主角。** 首页是主视觉，情报是轮播，干员是立绘，设定是文字，泰拉万象是场景，更多内容是四条带。没有哪一屏同时强调两样东西。
3. **标题写三遍。** 栏目名同时出现在导航（小）、右栏计数（中）、幽灵标题（巨）。三个尺寸、三个位置，既是导航又是装饰。
4. **整站等比缩放。** 用 rem + 视口相关的根字号，让版式在不同分辨率下保持比例；竖屏另起一套布局，连设计稿的基准宽度也换一张。
5. **只用一个彩色。**

## 可改进之处

第三方的改版练习指出过旧版官网的一些问题，其中部分在现版已经解决，仍可作为设计时的检查项：

- 导航默认隐藏、需要额外点击才能看到 → 现版已常驻顶部。
- 下载入口占用过多首屏空间。
- 干员页一次展示的阵营与角色偏少，切换层级偏深。
- 设定页容纳内容有限，延展性不足。
- 幽灵标题的对比度很低（`#242424` 对 `#000000`），只能作为装饰，不能作为唯一的标题。
