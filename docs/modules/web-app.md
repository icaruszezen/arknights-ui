# 网页与应用

> 风格来自规则，不来自画面。把直角、黑白灰加一个信号色、细线、中英成对、数据体的数字带进网页和应用里，而不是把游戏的界面搬过来。

前面各篇记的是官网和游戏画面里实际的样子。这一篇讲这些规则落到一般的网页、工具、后台上时怎么取舍，是 [`packages/react`](../../packages/react) 组件库的依据。这里的取值大多是本仓库的设计决定，可信度标作**估计**；有出处的会写明。

## 为什么不能照搬

游戏界面是为一块 16:9 的横屏、一根手指、一个固定的画布设计的。搬到网页上会碰到几件事：

| 游戏 / 官网里 | 放进网页时的问题 |
| --- | --- |
| 尺寸按 1280 × 720 或 1920 × 1080 定死，靠缩放根字号适配 | 网页不能改别人的根字号；在应用里，每个按钮都 60px 高太占地方 |
| 永远是黑底，明暗只在面板之间切换 | 阅读和工具型的页面需要亮色（[衍生品牌](sub-brands.md)：“阅读与工具型用亮色”） |
| 按 `(orientation: portrait)` 切换布局 | 平板竖屏、半屏的窗口会落到手机的布局里 |
| 通栏的确认弹窗、左上角的返回 + 主页、右上角的资源条 | 这些是游戏场景里的固定物件，网页有自己的习惯（居中的弹窗、面包屑、页头） |
| 选项摆在面上、没有输入框和表格 | 网页离不开文本输入、下拉、表格、分页 |

所以库分成了两部分：主入口按这一篇的规则做；照实机画面做的组件放进单独的游戏入口，不再演进。

## 保留什么

这几条在任何页面上都成立，是“舟味”的来源：

1. **直角。** 面板、按钮、输入框、标签、弹窗都是直角矩形。圆角只给卡片（2px）、头像、胶囊形的小标签，和 [几何语言](../foundations/geometry.md#圆角出现在哪) 的清单一致。
2. **黑白灰承担九成，一个信号色。** 一屏里实心的信号色只有一两块——通常是主按钮和当前项。
3. **线比面多。** 分区靠 1px 的细线；表格只在行与行之间画线，不给每行铺底色。
4. **悬停整块换色。** 按钮、菜单项、分段选项悬停时前景和背景对调，300ms。
5. **数字用数据体。** 页码、统计、时间、编号都用 Bender 一类的等宽字体，补零、带分母。
6. **中英成对。** 标题、表单项名、小节名后面可以跟一行窄体的英文小字。
7. **选中整块换色。** 不只靠一个小勾或一圈细描边（[表单控件](../elements/forms.md)）。

## 明暗两套

| 语义 | 暗色 | 亮色 | 说明 |
| --- | --- | --- | --- |
| 画布 | `#000000` | `#f2f2f2` | 暗色是官网（实测）；亮色与森空岛的底同值 |
| 默认的面 | `#1d1f20` | `#fdfdfb` | 官网的深色面板（实测）；游戏的纸白面板（社区） |
| 抬起的面 | `#272727` | `#ffffff` | 卡片、浮层 |
| 控件的底 | `#313131` | `#dbdcdd` | 设置页未选中的块（实机截图）；仓库分类未选中的底（实机裁图） |
| 主文字 | `#ffffff` | `#323232` | |
| 次要文字 | `#ababab` | `#585858` | 都在 4.5:1 以上：暗色在默认面上 7.2:1，亮色在画布上 6.4:1 |
| 细线 / 描边 | 白 30% / 50% | 字色 20% / 60% | 亮色的描边 60% 压在纸白上是 3.7:1，够得上控件边界的 3:1 |
| 信号色用作文字 | 原色 | 压暗到 45% | 青蓝、蓝、黄、橙都过 4.5:1 |
| 报错的文字 | 危险红提亮到 75% | 告警红 `#a32339` | 原色的危险红在抬起的面上只有 3.5:1 |

“反色面”是与所在主题相反的那一面：暗色主题里是纸白，亮色主题里是近黑。它对应游戏里“纸白说‘看这里’”——一屏最多一两块。

石墨（`#424242` 半透明）和纸白（半透明）两种面板保留下来，用在压在图片、场景上的地方，不跟主题变。

取值的唯一来源是 [`tokens.json`](../../tokens/tokens.json) 的 `theme` 一组。主题写在祖先元素的 `data-ark-theme` 上（`dark` / `light` / `auto`），一棵子树的明暗用 `data-ark-tone`。

## 尺寸

| 档 | 高度 | 用在哪 | 出处 |
| --- | --- | --- | --- |
| `xs` | 1.5rem | 小条、标签式的按钮 | 官网 READ MORE（实测） |
| `sm` | 2rem | 工具栏、表格行里的操作、紧凑的表单 | 估计 |
| `md` | 2.5rem | 默认 | 估计；实机设置页的开关、滑块折到 720p 约 40px |
| `lg` | 3rem | 宽松的表单、弹窗的操作 | 估计；实机的分段选项约 48px |
| `xl` | 3.75rem | 落地页的主行动：中英两行、文字贴左、箭头贴右 | 官网“更多情报”（实测） |

字号跟着档位走：`xs` 0.75rem，`sm` / `md` 0.875rem，`lg` 1rem，`xl` 1.25rem。正文从 1rem 起（官网公告正文，实测）。

点击区：可见形状不到 44px 的几档，触屏上撑到 44px；用鼠标时不撑，否则表格里一行一行的小按钮会互相盖住。

## 响应式

- 按**宽度**切换，断点 48rem。窄于它时：顶栏的导航收成全屏菜单，应用的侧栏收进左边的抽屉，弹层通栏贴底。
- 组件自己的编排按**它所在容器的宽度**切换（容器查询）：表单项的左右排在容器窄于 36rem 时退回上下排。
- 窄屏重新编排，而不是把宽屏缩小（[布局与层级](../foundations/layout-and-depth.md#响应式)）。

## 浮层与弹层

| 东西 | 做法 | 理由 |
| --- | --- | --- |
| 确认弹窗 | 居中的直角面板，上沿一条色边；取消在左、确认在右，各占一半宽，各带一个固定的图形（圆圈叉、圆圈对勾） | 通栏的横带在应用里太重；按钮对开、位置固定、图形固定这几条照 [反馈](../elements/feedback.md) |
| 确认的颜色 | 建设性的是信号色，不可撤回的是红色 | 游戏里的暗红标的是“要花掉东西”，网页上红色留给删除一类 |
| 内容弹层 | 居中，最宽 24 / 36 / 56rem；下层整页压暗并模糊 | 毛玻璃表达“盖在上面”（[布局与层级](../foundations/layout-and-depth.md)） |
| 抽屉 | 从右（详情）、左（导航）、下（窄屏的操作）滑入；主画面压暗但不模糊 | [面板与卡片](../elements/panels-and-cards.md#抽屉与浮层) |
| 提示、菜单、下拉 | 浏览器顶层里的浮层：反色的小块（提示），抬起的面加细线（菜单），反色的面（下拉的选项） | 下拉的“已选的深底、可选的浅底”照官网的语音下拉（实测） |
| 轻提示 | 提示条的样子，叠在视口一角，底下一条走时的细线；悬停时停住 | 估计 |

Esc 先关最上面的一层：浮层开在弹窗里时，第一次 Esc 只关浮层（[反馈](../elements/feedback.md) 第 4 条“返回先关最上面的一层”）。

## 表单

[表单控件](../elements/forms.md) 一篇的写法照做，补了网页需要而游戏里没有的：

| 控件 | 做法 |
| --- | --- |
| 输入框、多行输入 | 控件底色的直角块，底边一条描边色的线；聚焦时这条线换成信号色，键盘聚焦再加一圈轮廓；报错时换成红色 |
| 勾选框 | 方形，选中整块换成信号色，里面一道对勾；半选是一道横线 |
| 单选框 | 菱形，选中时中间填一块信号色。菱形把它和方形的勾选框区分开 |
| 下拉 | 当前项是控件底色的块、左缘一条 4px 的信号色边；展开的选项用反色的面 |
| 表单项 | 默认项名在上、控件在下；设置页的写法（项名在左、下面一条定长的线）是一个选项 |

选中的蓝：实机是 `#0075a8` 配白字，库里跟随信号色（默认青蓝配黑字），换信号色时一起变。要照实机做，把信号色换成 `--ark-color-signal-info-ink`、信号色上的字换成白色。

## 数据

| 东西 | 做法 |
| --- | --- |
| 表格 | 行与行之间一条细线，表头下面一条描边色的线；表头是窄体的灰色大写小字；数字列用数据体、靠右；选中的行左缘一条 4px 的信号色边（画成内阴影，不占宽度） |
| 分页 | 页码用数据体、补零到两位；当前页是信号色的实块；窄处是 `‹ 03 / 12 ›` |
| 面包屑 | 第一级后面是双斜杠，往后是单斜杠，和日期、计数是同一种写法 |
| 步骤 | 一根轴线串着方形的编号节点：完成的反色并换成对勾，当前的是信号色，还没到的只有细边 |
| 时间轴 | 刻度尺：一条 1rem 的短线接数字，两格之间夹着更短的分格（官网图集页，实测） |
| 头像 | 方形；没有图片时显示名字的两个字符，窄体；状态角标靠实块 / 空心区分 |
| 骨架 | 直角的灰块，明暗缓缓起伏 |

## 不做什么

- 不做大圆角、渐变、发光、阴影很重的卡片。
- 不给每一块都加切角、编号、条纹——它们是点缀（[设计总纲](../00-overview.md#常见误区)）。
- 不把游戏画面的固定物件（返回 + 主页、资源条、作战 HUD）当成网页的组件用。
