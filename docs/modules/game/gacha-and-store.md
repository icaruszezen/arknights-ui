# 游戏 · 寻访与采购中心

> 寻访是全游戏最“有戏”的界面：大图、视差、仪式感。采购中心是最“像应用”的界面：卡片、标签页、库存。

> 本篇为观察归纳，数值为估计。

## 干员寻访

- **一张主视觉撑满全屏。** 每个卡池是一整屏的横幅：当期干员的立绘占据大部分画面，卡池名用专门设计的标题字。
- **视差。** 多名干员立绘大小不同、前后叠放，滑动时以不同速度位移。大小差异暗示远近，视差把透视感做实。这是扁平界面里少数主动制造纵深的地方。
- **卡池切换是横向轮播。** 左右滑动或点击侧边的卡池缩略条切换。
- **两个行动按钮。** “寻访一次”与“寻访十次”并排，按钮上直接印着消耗的合成玉数量。十连的按钮更醒目。
- **概率与规则是次级入口。** 以小号文字链接的形式放在角落，点击后以浮层展开。
- **抽取演出。** 点击后进入一段固定的演出：拉开包、光效透出、逐个揭示。光的颜色在揭示之前就暗示了稀有度。这是“允许发光”的时刻。

### 标题字是独立设计

每个限定卡池、每个活动都有自己的标题标识（Logotype）：中英双语、带有该活动题材的装饰。它们风格各异，但进入界面后被统一放置在固定的位置和尺寸里。

## 采购中心

- **顶部标签页。** 可露希尔推荐、源石交易所、组合包、时装商店、凭证交易所、家具商店等并列。
- **卡片 + 投影。** 商品以卡片呈现，带投影，表达“可以拿走的东西”。这是全游戏最接近常规扁平化设计（卡片、阴影）的页面。
- **价格贴底。** 卡片底部一条深色带，写货币图标与价格。售罄的卡片整体压暗并盖上标记。
- **首次进入的介绍插画。** 第一次进入采购中心时有一张可露希尔的介绍图，常被拿来分析焦距控制：背景中心亮度溢出、人物带轮廓光、前后各有一层失焦的装饰文字，一张平面图里做出了多个光源和明确的纵深。

### 迭代中的经验

| 问题 | 改进 |
| --- | --- |
| 家具商店里看不出一套家具是否已买齐 | 购买时直接显示“是否已购买完整套件” |
| 凭证交易所左侧导航拥挤 | 重设样式，预留更多空位，为后续功能留余地 |
| 仓库物品多了难找 | 增加分类标签 |
| 兑换物品时不知道自己已有多少 | 活动商店显示库存；常规采购中心一度没有，用户需要来回跳转查看 |

最后一条是一个普遍适用的原则：**在做决定的地方，把做决定所需的信息都摆出来。**

## 规范

| 项 | 值 | 可信度 |
| --- | --- | --- |
| 寻访主视觉 | 全屏，人物偏一侧，另一侧留给标题与规则 | 估计 |
| 视差层数 | 2–4 层，位移量与图层“远近”成比例 | 估计 |
| 行动按钮 | 双色拼块：左侧代价、右侧动作；十连用更亮的主色 | 估计 |
| 代价数字 | 数据体 Bold，带货币图标 | 估计 |
| 商品卡片 | 直角，石墨或纸白底，`--ark-shadow-panel` | 估计 |
| 卡片价格带 | 高 28–36px，深色，价格右对齐 | 估计 |
| 标签页 | 选中项反白或信号色底条 | 估计 |
| 限时角标 | 橙色（`--ark-color-signal-accent`）小标签 + 剩余时间 | 估计 |
| 稀有度光效 | 揭示前以光色预告稀有度 | 估计 |

## 可借鉴的做法

1. **用大小与视差做纵深。** 不需要 3D，两三层不同速度的平面就够了。
2. **代价印在按钮上。**
3. **仪式感集中在一处。** 光效、粒子、长演出只出现在抽取结果这一个时刻，其余界面保持克制。
4. **列表页老老实实用卡片。** 商店是工具型页面，可读、可比、可扫视比风格更重要。
5. **决策信息就地给全。** 库存、是否成套、限购次数。
