# 游戏 · 作战

> 关卡选择是一张地图，作战界面是一块 HUD。信息贴边，战场留在中间。

> 本篇原先全是观察归纳。2026-10-07 对实机截图核对了一遍：作战 HUD、关卡选择的形状、颜色和尺寸改成了量得的值，标「社区（实机截图）」；没有取到截图的部分仍是估计。

## 关卡选择

- **地图式的节点。** 关卡不是列表，而是一条横向延伸的路线：每个关卡是一条带编号的横条（`1-7`、`TR-1`），节点之间用线相连，支线向上下分叉。
- **节点是一条白底深字的横条。** 编号上方一行极小的 `OPERATION`，左端一个六边形的通关标记（蓝色实心是已通关），右端一个圆形的掉落缩略图。**选中的那一条变成黑底白字。** 这是主线第五章的样子；活动关卡的节点各有各的皮肤，结构相同。
- **连线是实白线。** 约 3px 粗，两点之间直连，角度不限。
- **编号用数据体。** 关卡编号是这一页的主要文字，中文关卡名是副标题。
- **右侧详情面板。** 选中节点后，右侧出现关卡信息：推荐等级、敌方情报、掉落物品，底部是“开始行动”按钮。
- **代价写在按钮上。** 开始行动按钮下面一条深色带写着理智消耗（如 `-21`）。
- **章节有各自的主题色与背景。** 不同章节、不同活动的地图背景、配色、标题字体各不相同，但节点、连线、详情面板的结构一致。
- **图纸化的场景。** 关卡地图常用白色体块表示建筑、等高线表示山岭，像一张建筑模型的俯视图。

## 编队

- 干员卡片排成两排，每排六张。没有取到空位的截图，带加号的虚框是估计。
- 卡片沿用干员列表的规则：立绘、职业图标、等级、稀有度。
- 多个编队用底部的一排标签切换，当前的那个是蓝色实底。

## 作战 HUD

![作战 HUD 线框](../../assets/battle-hud.svg)

| 区域 | 内容 | 设计要点 |
| --- | --- | --- |
| 顶部居中 | 敌方击杀数 / 总数、我方生命点数 | 一块半透明黑底的**直角矩形**，两端和两项之间各一条短竖线。击杀配橙色的准星，生命配蓝白的塔形 |
| 左上 | 设置 | 一块深色的方块 |
| 右上 | 倍速、暂停 | 两块约 5rem 见方的深色方块，直角，底下一圈软投影。倍速是 `2X` 加双三角，文字在上、图形在下 |
| 底部 | 可部署干员卡带 | 每张卡顶部并排两格：浅灰底的职业图标、黑底的费用；选中项上浮并加描边 |
| 右下 | 当前费用、剩余可部署数 | 费用是全屏最大的数字，前面是菱形里一个 C 的图标；底板**下缘**的细条表示费用回复进度；再下面一条深色带写“剩余可放置角色：8” |
| 战场中 | 单位下方的生命条、技力条；可部署格高亮 | 两条细条紧贴，直角 |

### 状态的表达

| 状态 | 表现 |
| --- | --- |
| 费用不足 | 干员卡面压暗，费用数字变**灰**（不是转红） |
| 再部署冷却 | 卡面压暗，覆盖倒计时数字 |
| 可部署位置 | 地块以半透明色高亮 |
| 选择朝向 | 干员周围出现菱形方向盘，拖向四个方向之一 |
| 技能就绪 | 单位头顶出现黄色菱形的提示；选中后技能图标下方一条黄绿色的 `READY` |
| 敌方进入 | 生命点数减少，屏幕边缘红色闪烁 |

### 代理指挥

代理指挥（自动重放）模式下，界面上下出现遮挡条以示“当前不可操作”。评论文章指出这些遮挡条挡住了画面，玩家看不清战况，也不利于录制分享。表达“只读”状态时，应避免遮挡正在被观看的内容。

## 可借鉴的做法

1. **信息贴四边，中间留空。** HUD 元素全部靠边，战场不被遮挡。
2. **最关键的数字最大。** 费用决定下一步能做什么，所以它最大。
3. **状态用明暗 + 数字表达。** 费用不足时卡片变暗、数字变灰，不需要额外文字。
4. **把列表画成地图。** 关卡之间的先后与分支关系用空间位置表达，比编号列表更直观。
5. **直接操作。** 朝向选择是在干员身上直接拖拽，而不是在别处点方向键。
