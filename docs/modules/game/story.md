# 游戏 · 剧情

> 剧情界面把控件藏到最少，把字体的表现力放到最大。章节标题是每一章的“电影片头”。

> 本篇为观察归纳，数值为估计。2026-10-07 只核对到两处实机：角落里的“跳过”按钮和各章封面上的章节编号。对话画面没有取到整屏截图，那一节仍是估计。

## 对话演出

- **全屏场景 + 立绘 + 底部文字。** 标准的视觉小说布局。场景图铺满，说话的角色立绘居中或分列两侧，未说话的一方压暗。
- **对话框没有“框”。** 文字区是屏幕底部的一片自下而上的黑色渐变，没有边框、没有圆角气泡。说话人名字在左（较小、偏灰），正文在右（白色）。
- **控件贴右上角。** 自动、跳过、回顾、隐藏界面等几个小按钮排在角落，不抢画面。“跳过”是一条 26px 高的近黑色小横条，白字后面跟一个三角；回顾（`LOG`）是一块浅灰的小方块。
- **演出指令很克制。** 立绘的出入场是淡入淡出与短距离平移；强调时用镜头震动、画面闪白或局部特写。
- **“信号不稳”的故障效果。** 局部画面被打成马赛克。分析文章举的例子不在对话里，而在干员报到的界面（动态的）和剿灭作战的背景地图（静态的）；它认为这是在暗示玩家是通过某种系统接入“博士”的视角，并拿《刺客信条》艾吉欧三部曲里记忆模糊、连接不稳时的画面处理作比。故障在这里不是装饰，而是叙事。对话演出里有没有同样的处理，本仓库没有取到截图。

> **2026-10-14 更正。** 这一条原先写“特定剧情节点会出现局部马赛克化或画面撕裂”，把文章里的例子安到了剧情上。原文说的是干员报到界面和剿灭作战的背景地图。

## 章节标题

每一章的标题页是一张独立设计的版面：巨大的英文标题、较小的中文标题、章节编号，叠在一张气氛图上。

- **章节编号是一个小方框。** 一个描边的小方块，上面 `EP`、下面两位数字，白色，贴在标题的上方或左侧。

- **拉丁衬线体为主角。** 章节标题大量使用衬线体，而不是界面里的无衬线体。早期章节多用现代衬线（Didot、Bodoni 一类，笔画粗细对比极强，既锐利又带古典装饰感）。也有例外：第五章的封面是加宽的无衬线粗体，带错位的色边；第十四章是碑铭式的衬线。
- **字体要对得上题材。** 分析文章对早期一个章节标题（`EVIL TIME`）提出过批评：背景人物的服饰是欧洲宫廷风格，使用冷兵器，而标题的字型偏现代；下方的两行俄文又过于圆润粗大，削弱了帝国应有的庄严感。后续章节换用了更古典的 Trajan（碑铭风格的大写体），并收紧字距、调低中文字重，协调性明显改善。
- **多语言并置。** 标题页常出现英文、中文，以及与该章势力对应的其他文字（西里尔字母等）。多种文字的组合丰富了版面，也暗示了世界观的地域性。

这一段演变本身是一条有用的经验：**衬线体不等于古典，无衬线体不等于现代；选字要看具体字型与题材的气质是否一致。**

## 档案与文本

这一节没有取到截图，全部是估计。

- 有出处的只有一句概括：游戏内**标题**以思源宋体为主，其他文字用思源黑体（机核《尝试优化〈明日方舟〉官方网站的设计》）。社区整理的字体清单里另有 Times New Roman 与 Georgia，用在正式语境的英文上。
- “档案正文用宋体”没有出处。官网上成段的文字全是黑体，见 [字体与排版](../../foundations/typography.md#成段的文字)。自己做的时候，长文本用黑体是有据可依的默认，宋体留给标题。
- 长文本的行高明显大于界面文字，行长受控。
- 档案条目用编号和细线分节。

## 可借鉴的做法

1. **阅读时让界面消失。** 没有边框的文字区比一个精致的对话框更不打扰。
2. **用字体讲题材。** 同一套界面骨架，换一款标题字就换了一种气质。
3. **特效要有叙事理由。** 故障效果之所以成立，是因为它在设定里说得通。
4. **标题换字体，正文不换。** 宋体和拉丁衬线留给标题和章节名，成段的文字仍用黑体。
