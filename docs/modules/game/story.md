# 游戏 · 剧情

> 剧情界面把控件藏到最少，把字体的表现力放到最大。章节标题是每一章的“电影片头”。

> 本篇为观察归纳，数值为估计。

## 对话演出

- **全屏场景 + 立绘 + 底部文字。** 标准的视觉小说布局。场景图铺满，说话的角色立绘居中或分列两侧，未说话的一方压暗。
- **对话框没有“框”。** 文字区是屏幕底部的一片自下而上的黑色渐变，没有边框、没有圆角气泡。说话人名字在左（较小、偏灰），正文在右（白色）。
- **控件贴右上角。** 自动、跳过、回顾、隐藏界面等几个小按钮排在角落，半透明，不抢画面。
- **演出指令很克制。** 立绘的出入场是淡入淡出与短距离平移；强调时用镜头震动、画面闪白或局部特写。
- **“信号不稳”的故障效果。** 特定剧情节点会出现局部马赛克化或画面撕裂。分析文章认为这是在暗示玩家是通过某种系统接入“博士”的视角，并指出这与《刺客信条》里“失去同步”的表现手法相似。故障在这里不是装饰，而是叙事。

## 章节标题

每一章的标题页是一张独立设计的版面：巨大的英文标题、较小的中文标题、章节编号，叠在一张气氛图上。

- **拉丁衬线体为主角。** 章节标题大量使用衬线体，而不是界面里的无衬线体。早期章节多用现代衬线（Didot、Bodoni 一类，笔画粗细对比极强，既锐利又带古典装饰感）。
- **字体要对得上题材。** 分析文章对早期一个章节标题提出过批评：背景人物的服饰是欧洲宫廷风格，使用冷兵器，而标题的字型偏现代；下方的西里尔字母又过于圆润粗大，削弱了帝国应有的庄严感。后续章节换用了更古典的 Trajan（碑铭风格的大写体），并收紧字距、调低中文字重，协调性明显改善。
- **多语言并置。** 标题页常出现英文、中文，以及与该章势力对应的其他文字（西里尔字母等）。多种文字的组合丰富了版面，也暗示了世界观的地域性。

这一段演变本身是一条有用的经验：**衬线体不等于古典，无衬线体不等于现代；选字要看具体字型与题材的气质是否一致。**

## 档案与文本

- 干员档案、世界观文本使用中文宋体与英文衬线体（Times New Roman、Georgia），营造文书感。
- 长文本的行高明显大于界面文字，行长受控。
- 档案条目用编号和细线分节。

## 规范

| 项 | 值 | 可信度 |
| --- | --- | --- |
| 文字区遮罩 | 自下而上 `#000` → 透明，高度约为屏高的 30–40% | 估计 |
| 说话人 | 中文黑体，较小，`--ark-color-neutral-gray-400` | 估计 |
| 正文 | 中文黑体 Regular，白色，行高 `--ark-font-leading-body` | 估计 |
| 未说话立绘 | 亮度降低 40–60% | 估计 |
| 立绘出入场 | 透明度 + 短距离平移，`--ark-motion-duration-base` 至 `--ark-motion-duration-slow` | 估计 |
| 控件 | 右上角，小号，半透明 | 估计 |
| 章节英文标题 | 拉丁衬线大写（现代衬线或 Trajan 式），字距收紧 | 社区 |
| 章节中文标题 | 中文宋体或黑体，字重低于英文 | 社区 |
| 档案正文 | `--ark-font-family-cjk-serif` + `--ark-font-family-latin-serif` | 社区 |
| 故障效果 | 局部色块 + 横向错位，单次不超过 1 秒 | 估计 |

## 可借鉴的做法

1. **阅读时让界面消失。** 没有边框的文字区比一个精致的对话框更不打扰。
2. **用字体讲题材。** 同一套界面骨架，换一款标题字就换了一种气质。
3. **特效要有叙事理由。** 故障效果之所以成立，是因为它在设定里说得通。
4. **长文本换字体。** 界面用黑体，文书用宋体，功能性与阅读性分开。
