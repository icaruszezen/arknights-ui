# 宣传物料

> 游戏外的每一张图，都像是从游戏里的某份文件、某本杂志、某张海报上撕下来的。

> 本篇为观察归纳。宣传物料种类多、风格随题材变化，这里只总结跨物料的共性。具体图片请到官方渠道查看，见文末与 [官方图片外链索引](../references/image-index.md)。

## 物料类型

| 类型 | 形态 | 设计重点 |
| --- | --- | --- |
| 活动主视觉（KV） | 横幅插画 + 活动标题标识 | 标题字是独立设计的 Logotype |
| 活动 / 更新公告图 | 纵向长图，分节说明 | 模板化：页眉、编号小节、时间与条件的键值对 |
| 干员介绍图 | 单张，立绘 + 信息栏 | “简历”式排版，字体字距规则固定 |
| 宣传片（PV） | 视频 | 动态排版、平面图形与角色的结合 |
| 时装品牌视觉 | 杂志封面、吊牌、品牌 Logo | 每个虚构品牌一套完整识别 |
| 音乐 / 专辑封面 | 方形封面 | 见 [衍生品牌 · 塞壬唱片](sub-brands.md) |
| 线下活动、周年、音乐会 | 主视觉、舞台、票面 | 每届独立主题，沿用版式习惯 |
| 设定集与周边 | 实体出版物、包装 | 把底纹、编号、标识印到实物上 |

## 共性特征

### 1. 标题是标识，不是文字

每个活动、每个卡池、每个主题曲章节都有一个专门绘制的标题标识：中英双语，带有该题材的装饰元素（纹章、书法笔触、机械结构、乐谱……）。风格跨度很大，但都遵守同一个构成：**英文大、中文小，或中文大、英文小，两者咬合成一个整体**，从不简单地上下并排两行字。

### 2. 版式沿用界面语言

宣传图上能看到与界面完全相同的元素：

- 细线分区、角标、编号（`01`、`VOL.`、`NO.`）
- 贴边的微缩英文与竖排小字
- 半调网点与噪点底纹
- 警戒条纹窄边
- 巨型半透明英文垫在人物身后
- 日期与时间用数据体

这使得一张宣传图即使去掉 Logo，仍然能被认出来。分析文章提到，这套底图处理方式“在游戏内外均以惊人的统一性被使用”。

### 3. 人物 + 平面图形

官方美术风格常被概括为：把简练的平面设计元素与角色、服装设定结合在一起。具体做法是让平面图形（色块、线条、文字）与人物**互相遮挡**——一部分在人物之前，一部分在人物之后——而不是把人物摆在一个设计好的背景板前面。

### 4. 低饱和 + 一个亮色

宣传图同样以黑白灰和低饱和色为主，每张只用一个高饱和色作为主题色。主题色随活动变化（蓝、红、金、绿……），但“只有一个”的原则不变。

### 5. 公告图是模板化的信息图

活动与更新公告通常是纵向长图，结构固定：

```
┌──────────────────────────┐
│ 页眉：活动标题标识 + 主视觉 │
├──────────────────────────┤
│ 01  活动说明               │  ← 编号 + 小节标题 + 细线
│     活动时间：MM月DD日 16:00 - MM月DD日 03:59
│     解锁条件：……           │  ← 键值对，值用粗体或主题色
├──────────────────────────┤
│ 02  新增干员               │
│     [立绘] 代号 / 职业 / 星级
├──────────────────────────┤
│ 03  新增时装 …             │
├──────────────────────────┤
│ 页脚：注意事项（小字）       │
└──────────────────────────┘
```

每一期只换主题色、页眉和底纹，骨架不动。

上面这张示意是归纳出来的版式。官网上公告的**正文**是另一种更朴素的写法（2026-10-07 读了一篇活动预告的原文）：

- 每一节先放一张 1560 × 500 的头图，再接文字。
- 小节用中文数字编号，整行粗体：`一、全新SideStory「…」，活动关卡开启`。没有 `01` 式的两位数字编号。
- 键值对是“**键粗体**加全角冒号，值常规字重”：`<strong>活动时间：</strong>10月09日 12:00 - 10月30日 03:59`。
- 要强调的值单独上色（那一篇用的是红色 `#c0392b`）：主要奖励里的干员、家具、凭证。
- 小标题用方头括号：`【打捞方案】`。
- 注意事项用 `◆` 起头，常规字重。
- 时间写作 `MM月DD日 HH:MM - MM月DD日 HH:MM`；需要年份时写 `2026年10月23日03:59`。

### 6. 干员介绍图是“简历”

排版规则见 [游戏 · 干员](game/operator.md#简历式的信息编排)：代号用思源黑体 Heavy 并收紧字距，其余信息用 Normal 字重，技能说明左对齐到图标右侧。

### 7. 虚构品牌的完整识别

游戏内的时装被归入若干虚构的服装品牌，每个品牌都有 Logo、标准字、主视觉、甚至杂志封面和吊牌。设计上的看点：

| 手法 | 例子（据社区分析） |
| --- | --- |
| 用字体类型定位品牌 | 高端定制用手写体；历史悠久的时装屋用衬线体并收紧字距；运动品牌用极粗的扩展无衬线体 |
| 入口模拟实物 | “时装回廊”的入口做成时装杂志封面与服装吊牌，英文用新古典衬线体 |
| 传统图形的几何化 | 把书法字形抽象成锋利的几何形，再叠加纹理 |
| 一个主色 | 每个品牌一个代表色，放回界面时仍由黑白灰统一 |
| 图形呼应品类 | 户外品牌用盾牌与树，极地品牌用化石与等高线，运动品牌用倾斜的平行线 |

这部分是学习“在一个统一的设计系统里容纳多个子品牌”的好材料。

### 8. 宣传片：动态排版

概念宣传片的评论集中在：扁平化的 UI 图形、硬朗的线条、对比鲜明而不失稳重的上色、用景深与光效营造场景。画面中的文字不是字幕，而是参与构图的图形——大字快速切入、细线扫过、色块遮挡转场。界面里“一个彩色、细线、巨字”的原则在动态里同样成立。

## 规范

| 项 | 做法 | 可信度 |
| --- | --- | --- |
| 主题色 | 每个活动 / 物料一个，其余用中性色 | 估计 |
| 标题标识 | 双语咬合；主文字占版面宽度的 40–70% | 估计 |
| 编号小节 | 数据体两位数字 + 中文小节名 + 1px 细线 | 估计。公告正文用的是“一、”“二、” |
| 键值对 | 键粗体加全角冒号，值常规字重；要强调的值上主题色 | 实测（官网公告正文） |
| 时间写法 | `MM月DD日 HH:MM - MM月DD日 HH:MM`，数字用数据体 | 写法实测；数据体是估计 |
| 注意事项 | `◆` 起头，位于每节末尾 | 实测（官网公告正文） |
| 人物与图形 | 至少一个图形元素在人物之后、一个在人物之前 | 估计 |
| 底纹 | 半调或噪点，局部使用 | 估计 |
| 微缩英文 | 贴边，可竖排 | 估计 |
| 版心 | 四周留出等宽边距，角落放角标或十字标 | 估计 |

> **2026-10-07 更正。** 键值对原先写的是“值用粗体或主题色”，键偏灰。官网公告的原文正好相反：键是粗体，值是常规字重。

## 做同人 / 衍生设计时

- 版式、配色原则、字体搭配方式都可以学习和使用。
- 不要直接使用官方的标题标识、Logo、立绘和图标；不要制作容易被误认为官方发布的公告、活动或周边。
- 标注“非官方”“同人作品”。
