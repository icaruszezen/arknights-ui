# 图标与符号

> 单色、几何、实心。图标像徽章而不像插画——每一个都能刻成钢印。

## 特征拆解

**1. 单色剪影。** 图标只有一个颜色（通常是白或黑），没有渐变、高光和描边层次。区分全靠轮廓。这使得同一个图标可以放在任何底色上，也可以直接缩小当作水印。

**2. 几何构形。** 轮廓由直线、45° 斜线和少量圆弧构成，转角锐利。职业图标是最典型的例子：八个职业各有一个抽象符号，都能装进同一个正方形或三角形的外框里。

**3. 三层结构（技能与职业图标）。** 社区对游戏内技能图标的拆解是三层：底色、图形、外框。底色表达类别（不同回复方式用不同底色），图形表达具体内容，外框统一规格。

**4. 阵营 Logo 是独立的标识设计。** 罗德岛、企鹅物流、莱茵生命、龙门近卫局等每个势力都有完整的标识，气质各异（有的是纹章，有的是企业 Logo，有的是书法变体），但都遵守单色、可缩放的规则。它们经常被放大、降低不透明度后压在面板背景里。

**5. 图标 + 双语标题是固定组合。** 入口永远是“图标 + 中文粗字 + 英文小字”。图标在左，大小约等于中文的字高。

**6. 小图标就是小几何。** 功能性的小图标不追求具象：方点、三角、菱形、短横线，就够表达“标注点、更多、稀有度、分隔”。星级在不同位置会写成五角星或菱形。

**7. 品牌延伸：虚构品牌的 Logo。** 游戏内的时装系列各有一个虚构的服装品牌，每个品牌都有成套的标识、字体选择和主视觉。它们的风格从衬线奢侈品牌到运动潮牌跨度很大，但放回游戏界面里时，又都被“单色 + 几何外框 + 黑白灰底”的规则统一住。

## 规范

| 项 | 做法 | 可信度 |
| --- | --- | --- |
| 颜色 | 单色；随所在面的前景色（白 / 黑 / 信号色）变化 | 估计 |
| 画板 | 正方形，图形占 70–80%，四周留等距空白 | 估计 |
| 线条 | 实心为主；需要线性图标时线宽统一，端点平头 | 估计 |
| 转角 | 尖角，不做圆角 | 估计 |
| 允许的角度 | 0°、45°、90° 为主 | 估计 |
| 与文字的搭配 | 图标高度 ≈ 中文大字的字高；间距 0.5–0.75rem | 估计 |
| 作为背景水印 | 放大到面板高度的 60–120%，不透明度 5–15% | 估计 |
| 外框 | 方形或三角形；同一组图标用同一种外框 | 估计 |

### 图标类型与用途

| 类型 | 形态 | 示例位置 |
| --- | --- | --- |
| 职业 | 抽象几何符号，方框内 | 干员卡片左上角、筛选栏 |
| 阵营 / 势力 | 完整标识，常带文字 | 干员详情、档案、面板水印 |
| 技能 | 具象小图 + 底色 + 方框 | 干员详情、作战中 |
| 资源 / 道具 | 具象物品 + 稀有度底色 | 仓库、奖励列表 |
| 功能 | 极简线性或实心图形 | 导航、设置、返回 |
| 指示 | 三角、菱形、方点 | 列表、标注、分页 |

## 自绘图标的建议

本仓库不收录任何官方图标。需要图标时：

- **功能图标**：使用开源图标库（如 Lucide、Tabler、Remix Icon），选线条平直、端点平头的款式，统一成单色。
- **类别符号**：按上表的画板规则自己画，优先用矩形、三角、斜线组合。
- **不要**描摹官方的职业图标、阵营 Logo 或游戏 Logo。需要展示时用外链指向 PRTS Wiki 或官网。

## Do / Don't

| Do | Don't |
| --- | --- |
| 单色实心 | 渐变、高光、多色图标 |
| 同组图标统一画板与外框 | 有的带框、有的不带，大小不一 |
| 图标永远配文字 | 只放图标让用户猜 |
| 把标识放大降透明当水印 | 在同一面板里放两个以上水印 |
| 自绘或使用开源图标 | 描摹、提取官方图标入库 |
