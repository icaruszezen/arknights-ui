# 底纹

> 平涂的色面上盖一层很轻的颗粒，留白就不会发飘。半调网点和警戒条纹是两张王牌。

## 特征拆解

**1. 半调网点（Halftone）。** 最常见的底纹。一片由密到疏的圆点——疏不是变淡，而是**点变小**：最密的地方相邻的点相切，往外越来越小，直到消失。点排在一张转了约 20° 的网格上。它来自印刷和漫画网点纸，给纯数字的界面带来一点“印出来的东西”的质感。官网整屏盖着一张这样的半调图，两侧各一片；游戏内几乎所有浅色面板的下半部分都有。

**2. 点阵。** 等大的小方点排成稀疏的方阵，四排一组，放在画面的角落。它和半调不是一回事：点一样大、间距很宽，像图纸上的定位点。官网泰拉万象屏的左下和右上各有一片。

**3. 噪点（Grain）。** 低密度、高颗粒的散点，铺在按钮和卡片的底色上。作用是让大面积留白不显得单薄，同时提高与上层文字的对比。

**4. 警戒条纹（Hazard stripe）。** 45° 的粗斜条，黄黑相间或同色深浅相间。它是工业现场的警示带，直接点明“危险 / 施工 / 限制”的语境。用法非常克制：只做窄窄的一条边，绝不铺满整个面。

**5. 斜线网格。** 方格加两条对角线，线很细、很暗，铺在最底层。官网背景即是如此。它像图纸的底格，与十字标、角标是同一套语言。官网的网格是 canvas 画的，样式表里读不到线距。

**6. 马赛克与故障（Glitch）。** 局部画面被打成色块，或文字出现横向错位。只在特定时机出现（加载、转场、剧情中的“信号不稳”），暗示玩家是通过某个终端在远程接入这个世界。

**7. 扫描线。** 细密的水平线叠在“投影”性质的面板上，配合透视倾斜，强化全息看板的设定。

**8. 内外统一。** 同样的底纹同时出现在游戏内、官网、宣传图和周边上。底纹本身就是品牌识别的一部分。

## 规范

| 底纹 | 参数 | 用在哪 | 可信度 |
| --- | --- | --- | --- |
| 半调网点 | 点距约 `0.95rem`（1920 基准下 15.2px），网格转约 20°；点径随浓度变化，从相切缩到消失；浅灰，用叠加模式（`mix-blend-mode: overlay`）盖在整屏上，看上去约两成白 | 画面两侧、角落、浅色面板下半部 | 实测（官网的半调图） |
| 点阵 | 点约 `0.25rem × 0.19rem`，横向点距 `2.25rem`、纵向约 `2.44rem`，四排；`#ababab` 的 45% | 画面角落 | 实测（官网泰拉万象屏） |
| 噪点 | 单色颗粒，不透明度 10–20% | 按钮、卡片、纯色底图 | 估计 |
| 警戒条纹 | 45°，条宽 6–12px，带高 6–24px | 面板顶边或底边、警告提示、限时活动 | 估计 |
| 斜线网格 | 方格 + 对角线，1px，白 5–15% | 最底层背景 | 估计（官网是 canvas 画的，读不到取值） |
| 虚线 | 实 0.25rem / 空 0.25rem，`#b2b2b2` | 次级分隔 | 实测 |
| 渐隐细线 | 白 30% → 透明 | 标题下方、行分隔 | 实测 |
| 扫描线 | 1px 线 / 3px 空，白 10% | 全息面板 | 估计 |

```css
/* 虚线分隔（官网实测） */
.rule--dash { height: 1px; background: var(--ark-pattern-dash); }

/* 一端渐隐的细线（官网实测） */
.rule--fade { height: 1px; background: var(--ark-pattern-fade-rule); }

/* 警戒条纹窄边 */
.hazard { height: 0.5rem; background: var(--ark-pattern-hazard); }

/* 半调网点：--ark-pattern-halftone 是一层遮罩，点径随浓度变化，左下最密、朝右上渐疏 */
.halftone {
  background: currentColor;
  mask: var(--ark-pattern-halftone);
}
```

### 半调是怎么做的

CSS 的遮罩之间只能相乘。把一张等大的圆点和一道渐变相乘，得到的是“越来越淡的点”，不是“越来越小的点”。

`--ark-pattern-halftone` 因此是一张内联的 SVG：一层方向渐变垫底，上面盖一层 50% 的柔边圆点（中心白、边缘黑），两者的亮度相加，过半的地方才留下。渐变越亮，圆点留下的部分越大，最亮处正好相切。取阈值用的是 `feColorMatrix`。

SVG 里写不了 rem，所以点距固定是 16px，不随根字号缩放。换方向要换一张图，生成的函数在 [`packages/react/src/internal/halftone.ts`](../../packages/react/src/internal/halftone.ts)。

> **2026-10-08 更正。** 原先的半调是“1px 的圆点、0.5rem 间距、靠遮罩渐隐”，是估计。把官网的半调图（`common_mask`）画到 canvas 上量：相邻两点的距离中位数是 7.62px（图是 960 宽，铺满 1920 的屏，所以是 15.2px），连线的角度中位数 20.6°，点是实心的浅灰（亮度 90 对底 7），大小随位置变化。点阵（`dots`、`dots_wide` 两张图）是这次才注意到的，原先把它和半调当成了一种东西。

### 叠加顺序

底纹永远在内容之下、底色之上：

1. 底色（平涂）
2. 斜线网格 / 噪点（整面，极淡）
3. 半调网点（局部，角落）
4. 内容（文字、图标、图片）
5. 警戒条纹（贴边，可压在内容层之上）

## Do / Don't

| Do | Don't |
| --- | --- |
| 网点只放一角，由大到小地消失 | 整面铺满均匀网点 |
| 警戒条纹做成窄边 | 把条纹当大面积背景 |
| 一个面上最多叠两种底纹 | 网点 + 条纹 + 噪点 + 扫描线全上 |
| 底纹的对比度压到“细看才有” | 底纹比文字还抢眼 |
| 故障效果只在转场和特定剧情出现 | 常驻的闪烁与抖动 |
