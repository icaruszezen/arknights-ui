# 导航

> 导航永远在同一个地方。官网是顶部一排双语标签，游戏是左上角“返回 + 主页”。

## 特征拆解

### 官网

**1. 双语标签。** 每个导航项是两行：上面英文窄体（1.375rem），下面中文小字（0.875rem）。英文是视觉主体，中文是说明。

**2. 只用颜色表示当前项。** 当前项整体变成青蓝，没有下划线、底色或加粗。

**3. 右栏计数。** 屏幕右侧一条竖线隔出窄栏，里面是当前分屏的编号与名称：`01 // 01 / 05 INFORMATION`。它相当于纵向的面包屑。

**4. 固定不动。** 六个分屏滚动切换时，导航与右栏原地不动，只有颜色和数字变化。

**5. 竖屏收进菜单。** 竖屏下导航折叠为汉堡按钮，展开后是全屏菜单：一项一行，每行 `7.5rem` 高、底部一条细线，英文（`2.25rem`）贴左、中文（`1.75rem`）贴右，中文下面压一条粗条，正好骑在这一行的底线上。各项自右滑入并淡入。这些 rem 以 750 宽为基准：375 宽的手机上，一行实际是 60px 高，字是 18px 和 14px。菜单按钮在顶栏最右、和右栏同宽的一格里。

### 游戏

**6. 返回 + 主页。** 所有二级页面的左上角是两个并排的直角矩形：左边一块深灰，里面一个又高又细的返回箭头；右边一块稍浅、更宽，中间是主页图标。两块之间只有一条窄缝，没有斜边。位置、大小从不改变。

**7. 隐藏式快捷导航。** 点主页块会展开一条横贯屏幕的半透明带：一根水平的轴线上串着一排圆形节点，每个节点是一个系统，名称和图标上下交错地挂在轴线两侧，用一小段虚线连到节点；当前所在的系统，节点外面多两圈同心圆。可以直接跳到任何一个系统，而不必先回到主界面。平时它是隐藏的，不占用空间，展开时主页块描一圈白边。这个设计常被拿来与《公主连结》的导航方式类比。

**8. 导航被包装成场所。** 主界面的入口不是一张功能列表，而是对应罗德岛本舰的不同区域。菜单因此有了空间感。

**9. 全局物品跳转。** 任何地方出现的物品图标都可以点开，查看来源并直接跳到对应关卡。物品本身就是导航入口。

### 标签页

**10. 实心块、底条或分段块。** 标签页有三种写法：选中项变成信号色的实心块、右端一个折线箭头，其余只留文字（官网的新闻分类）；在选中项下方加一条 4px 信号色条，其余文字变灰；或者每一项都有底块、连成一条，选中项明暗对调（游戏内仓库的分类）。

## 规范

### 官网顶栏（实测）

| 项 | 值 |
| --- | --- |
| 英文 | Oswald Medium，`1.375rem`，行高 `normal` |
| 中文 | 思源黑体 Medium，`0.875rem` |
| 默认色 | `#ffffff` |
| 当前项 | `#18d1ff`（英文与中文同时变色） |
| 过渡 | `color .3s` |
| 悬停 | 与当前项同色（`#19d1ff`） |
| 项间距 | `margin: 0 2.5rem` |
| 竖屏菜单的行 | `height: 7.5rem`，两端对齐，`border-bottom: 1px solid hsla(0,0%,100%,.3)`（750 基准；折半 `3.75rem`） |
| 竖屏菜单的字 | 英文 Oswald Medium `2.25rem`，中文思源黑体 Medium `1.75rem`（折半 `1.125rem`、`0.875rem`） |
| 竖屏菜单的粗条 | 中文下方，`height: .375rem`，`bottom: -.1875rem`，`currentColor`（折半 `.1875rem`、`-.09375rem`） |
| 竖屏的菜单按钮 | 顶栏最右一格，宽 `5.75rem`（折半 `2.875rem`，和右栏同宽）；三条 2px 的白色横杠，`2.625rem × 2.375rem` |
| 竖屏的菜单底 | `rgba(0,0,0,.9)`，上面让出顶栏、右边让出右栏；列表内边距 `1.25rem 2.25rem 0 3.375rem`；最下面一栏 `TOOLBOX`，是一排社交图标 |
| 竖屏菜单的入场 | `opacity .2s, transform .2s`，起点 `translateX(20%)` |
| 右栏的宽度 | 约 `14.75rem`：计数块宽 `10rem`，右侧留 `2.375rem` |
| 右栏计数数字 | Novecento Sans Wide DemiBold，`5.4rem`，青蓝 |
| 右栏“当前 / 总数” | Bender Regular，`1.125rem`，在数字右侧 |
| 右栏英文标签 | Novecento Sans Wide DemiBold，`1.125rem`（1280 宽时 12px），字距 `0.1em`，在数字下面 |

> **2026-10-07 更正：** 右栏计数数字原先写的是“Bender Bold”，实际是宽体；英文标签的“12px”是 1280 宽时的读数，折回 1920 基准是 `1.125rem` 而不是 `0.75rem`。

### 游戏内导航

| 项 | 做法 | 可信度 |
| --- | --- | --- |
| 返回按钮 | 直角矩形，`142 × 45px`（1280 × 720 的实机裁图），底色 `#313131`，白色细线箭头贴左，高约为块的六成 | 社区（实机裁图） |
| 主页按钮 | 紧邻返回的直角矩形，更宽（约 `208 × 45px`），稍浅的灰（裁图取色 `#3c3b3b` 上下），图标居中；展开时描一圈 2px 白边 | 社区（实机裁图） |
| 快捷导航 | 通栏的黑色半透明带；一根轴线上串着圆形节点，名称与图标上下交错，虚线连到节点；当前项是放大的同心圆。只有中文，没有英文小字 | 社区（实机截图） |
| 资源条 | 贴右上角。每一项是**图标 + 数字**，没有文字名称；有上限的写成小而灰的分母（`0/200`）；可以购买的资源后面跟一个圆形的加号。主界面上数字直接压在场景上，二级页面是半透明的深色块 | 社区（实机截图） |

> **2026-10-07 更正：** 这一节原先把返回、主页写成“斜切的平行四边形”，把快捷导航写成“中文 + 英文小字的横条”，都是凭印象归纳的。对照实机后改成上面的写法。全局只用 45° 这条规则仍然成立，只是这两个块上没有斜边。

### 标签页

| 写法 | 选中 | 未选中 | 可信度 |
| --- | --- | --- | --- |
| 实心块 | 信号色底 `#18d1ff`、黑字，右端一个黑色折线箭头（`0.4375rem` 宽） | 白字无底，悬停变信号色字 | 实测（官网新闻分类） |
| 底条 | 信号色文字 + `4px` 底条 | `#ababab` 文字 | 文字的颜色有实机出处（基建的干员筛选：选中蓝字、未选中灰字）；底条是估计 |
| 分段块 | 明暗对调：浅色页面上是 `#323232` 底白字 | 连成一条的浅灰底（裁图取色 `#dbdcdd`–`#f4f4f5`）深字，项与项之间一条半高的短竖线；每一项前面带图标 | 社区（实机裁图） |

实心块的尺寸（官网实测）：`width: 5.625rem; height: 1.25em; padding: 0 .5rem 0 .125rem; margin-right: 1rem`，思源黑体 Bold `1rem`，`transition: color .3s, background-color .3s`；箭头用 `opacity .3s` 淡入。

> **2026-10-07 更正：** 实心块原先写的是“白底黑字”。官网样式表里选中项是 `color: #000; background-color: #18d1ff`，白色只出现在别的按钮的悬停态。

```html
<nav class="ark-nav" aria-label="主导航">
  <a href="#index"><span lang="en">INDEX</span><span>首页</span></a>
  <a href="#information" aria-current="location"><span lang="en">INFORMATION</span><span>情报</span></a>
</nav>
```

```css
.ark-nav { display: flex; gap: var(--ark-space-6); }
.ark-nav a { display: grid; color: var(--ark-color-neutral-white);
             transition: color var(--ark-motion-duration-base); }
.ark-nav [lang="en"] { font: 500 var(--ark-font-size-nav)/1.3 var(--ark-font-family-latin-condensed); }
.ark-nav span:last-child { font: 500 var(--ark-font-size-label)/1.4 var(--ark-font-family-cjk-sans); }
.ark-nav [aria-current] { color: var(--ark-color-signal-info); }
```

> 当前项只靠颜色区分时，务必同时提供 `aria-current`，并考虑为色觉障碍用户补一个非颜色的标记（如 4px 底条）。

## Do / Don't

| Do | Don't |
| --- | --- |
| 导航位置全站固定 | 不同页面导航位置不同 |
| 英文与中文成对，大小有别 | 中英文同字号并排 |
| 提供从任意页面直达任意系统的捷径 | 强迫用户层层返回 |
| 告诉用户“现在在第几屏 / 共几屏” | 长页面没有任何位置提示 |
| 窄屏重新编排成大号列表 | 把横排导航缩小到看不清 |
